# MiniFile

Minimalist Android File Manager + PC Companion.

## Features
- Minimalist Material 3 UI for browsing Internal Storage, App Data, and External/USB OTG storage.
- File operations: Copy, Cut, Paste, Rename, Delete, Create Folder/File, File Details.
- Built-in Wireless FTP Server & PC Companion (CLI & GUI).
- Power tools: Hidden files toggle, Built-in Text Viewer/Editor, Zip Archive Compress/Decompress, `.nomedia` manager.
- Favorites / Bookmarks with direct Copy/Move target picker.
